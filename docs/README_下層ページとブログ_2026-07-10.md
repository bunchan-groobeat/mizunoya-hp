## 1. 配色トーンの切り替え方法（★最重要）

**書き換えるのは1ファイル・2行だけ。**

- ファイル: `assets/css/theme.css`
- 場所: 先頭の「★★★ 配色トーン切替 ★★★」ブロック内、**30〜31行目**の【適用】2行

### 現在（赤メイン＝既定）
```css
  --brand-main: var(--brand-red);
  --brand-sub:  var(--brand-navy);
```

### 紺メインに戻すには（この2行を入れ替えるだけ）
```css
  --brand-main: var(--brand-navy);
  --brand-sub:  var(--brand-red);
```

これで **トップ＋下層6ページ＋ブログ** のメイン/サブ配色が一斉に切り替わる。

### トーンに依らず固定している色（意図的）
- **電話CTA・フローティング電話ボタン＝赤**（緊急連絡の視認性。`--brand-red` 固定）
- **フッターベタ・ヒーロー背景・CTA帯＝紺**（締め色。指示書§2「フッターは紺ベタ」。`--brand-navy` 固定）

### 見え方の目安
- 赤メイン: 看板ロゴの赤が主役。サービスカードの枠・見出しEN・リンクが赤、締めが紺。
- 紺メイン: 認証工場らしい堅実な紺が主役（元の下層ページのトーンに近い）。電話だけ赤のまま。

### 既知の軽微点
- `assets/css/theme.css` の `.svc_card::before`（サービスカード内側の細枠、赤30%）だけはトーンに追従せず赤のまま。ごく薄い装飾のため実害小。紺メイン確定後に追従させたい場合は連絡を。

## 3. お知らせ/ブログ雛形（microCMS方式・J-DRY踏襲）

### ファイル
- `blog.html` … 記事一覧（アーカイブ）
- `blog-article.html` … 記事詳細（`?id=` で記事を切替）
- `assets/js/config.js` … microCMS接続情報（**現在は空欄＝未接続**）
- `assets/js/blog.js` … 一覧・記事の描画。未接続時はダミー記事3件で動作

### 未接続時の動作（今の状態）
- 一覧: `blog.html` の静的ダミー3件を表示
- 記事: `blog-article.html?id=sample-1`〜`sample-3` でダミー本文を表示
- ダミー画像・本文は `assets/js/blog.js` の `DUMMY` に集約（画像パス一元管理）

### microCMS接続時にやること（J-DRYと同じ手順）
1. microCMSで「blog」API（スキーマ: title / body(リッチ) / thumbnail / category / publishedDate）を作成
2. **読み取り専用（GET）APIキー** を発行
3. `assets/js/config.js` の `MICROCMS_SERVICE_DOMAIN` と `MICROCMS_API_KEY` を記入
4. これだけで一覧・記事とも自動取得に切替（ビルド不要・公開で即時反映）

※ 書き込み/管理権限のキーは絶対にconfig.jsへ書かない（静的サイトのため閲覧者に見える）。

### ナビゲーション
- グローバルナビには「お知らせ」を**まだ追加していない**（公開判断前のため）。
- 公開時は各ヘッダーの `<nav>` に1行 `<li><a href="blog.html">お知らせ</a></li>` を追加すればよい。
